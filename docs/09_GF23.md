# 09 — GF(2³) para el apéndice

## Intuición en una página

Un **campo** es un conjunto donde puedes sumar, restar, multiplicar y dividir (salvo por 0) con las reglas “bonitas” de la aritmética.

`GF(2³)` tiene **8 elementos**. Puedes verlos como:

- enteros `0..7`, o
- polinomios en `x` con coeficientes en `{0,1}` de grado &lt; 3, p. ej. `5 = 101₂ = x² + 1`.

### Suma

Suma de polinomios módulo 2 = **XOR** de los enteros.  
Por eso la tabla de suma es la tabla del XOR.

### Multiplicación

Multiplicas polinomios y reduces módulo un polinomio **irreducible** de grado 3 (como reducir módulo un primo en enteros).

Default en el código: `x³ + x + 1` (`0b1011`).

```bash
python gf/gf8_tables.py
# si el slide 124 usa otro:
python gf/gf8_tables.py --mod 0b1101
```

Salida: `results/gf23_tables.txt` (binario y decimal).

## ¿Por qué aparece esto en un curso de seguridad?

AES trabaja internamente en **GF(2⁸)**. Aquí el profesor pide GF(2³) como versión de juguete para practicar las tablas antes de ver campos más grandes.
